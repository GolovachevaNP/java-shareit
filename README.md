# ShareIt

**ShareIt** - backend-сервис для обмена и временной аренды вещей.

Пользователи могут размещать вещи, доступные для аренды, находить нужные предметы и бронировать их на определённые даты. Владельцы управляют заявками на бронирование, а пользователи после завершённой аренды могут оставлять комментарии.

Если нужной вещи ещё нет в сервисе, пользователь может создать запрос, на который другие пользователи смогут ответить, добавив подходящую вещь.

Проект состоит из двух отдельно запускаемых приложений:

- **ShareIt Gateway** — принимает внешние HTTP-запросы, выполняет валидацию входных данных и передаёт корректные запросы основному сервису;
- **ShareIt Server** — содержит бизнес-логику приложения и взаимодействует с базой данных.

## Основная функциональность

### Пользователи

- создание пользователей;
- редактирование данных;
- получение пользователя по идентификатору;
- получение списка пользователей;
- удаление пользователей

### Вещи

- добавление вещей;
- редактирование информации о вещи владельцем;
- получение информации о вещи;
- получение списка вещей владельца;
- поиск доступных для аренды вещей

### Бронирования

- создание бронирования на выбранный период;
- подтверждение или отклонение бронирования владельцем вещи;
- получение бронирования по идентификатору;
- получение списка бронирований пользователя;
- получение бронирований принадлежащих пользователю вещей;
- фильтрация бронирований по состоянию:
  - `ALL`;
  - `CURRENT`;
  - `PAST`;
  - `FUTURE`;
  - `WAITING`;
  - `REJECTED`;
- отображение последнего и ближайшего будущего бронирования для вещей владельца

### Комментарии

Пользователь может оставить комментарий к вещи после завершения её аренды

### Запросы на вещи

Если нужной вещи нет в сервисе, пользователь может создать запрос

Поддерживаются:

- создание запроса;
- просмотр собственных запросов;
- просмотр запросов других пользователей;
- получение запроса по идентификатору;
- добавление вещи в ответ на существующий запрос

### Валидация и обработка ошибок

- валидация входящих данных на уровне `gateway`;
- передача корректных запросов в основной сервис;
- централизованная обработка ошибок

## Архитектура

Приложение разделено на два сервиса:

```text
Клиент
   │
   ▼
ShareIt Gateway :8080
   │
   │ REST
   ▼
ShareIt Server :9090
   │
   ▼
PostgreSQL
```

### ShareIt Gateway

Gateway является внешней точкой входа в приложение.

Он отвечает за:

- приём HTTP-запросов;
- проверку входных данных;
- предварительную валидацию;
- передачу корректных запросов в `ShareIt Server`.

### ShareIt Server

Server содержит основную бизнес-логику:

- пользователей;
- вещей;
- бронирований;
- комментариев;
- запросов на вещи.

Серверная часть взаимодействует с реляционной базой данных.

Внутри приложения используется слоистая архитектура:

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
PostgreSQL
```

- **Controller** — принимает REST-запросы;
- **Service** — реализует бизнес-логику;
- **Repository** — отвечает за работу с данными.

## База данных

Для хранения данных используется реляционная база **PostgreSQL**.

Основные сущности предметной области:

- пользователи;
- вещи;
- бронирования;
- комментарии;
- запросы на вещи.

Основные связи:

- каждая вещь принадлежит владельцу;
- бронирование связывает пользователя и вещь;
- комментарий связан с пользователем и вещью;
- запрос принадлежит пользователю;
- вещь может быть добавлена в ответ на существующий запрос.

При проектировании базы данных учитывались связи между сущностями и сценарии получения информации о текущих, прошлых и будущих бронированиях.

## Бизнес-правила

### Бронирование

Пользователь может создать заявку на аренду вещи на определённый период.

Владелец вещи может:

- подтвердить заявку;
- отклонить заявку.

Для бронирований поддерживаются состояния:

```text
ALL
CURRENT
PAST
FUTURE
WAITING
REJECTED
```

### Комментарии

Оставить комментарий может пользователь, который ранее арендовал вещь и завершил бронирование.

### Поиск вещей

Поиск возвращает вещи, доступные для аренды и соответствующие поисковому запросу.

### Запросы

Если подходящей вещи в сервисе нет, пользователь может создать запрос. Другой пользователь может добавить вещь и связать её с этим запросом.

## Запуск приложения

### Требования

Для запуска необходимы:

- JDK;
- Maven;
- Docker;
- Docker Compose.

### Клонирование репозитория

```bash
git clone https://github.com/GolovachevaNP/java-shareit.git
cd java-shareit
```

### Сборка проекта

```bash
mvn clean package
```

### Запуск

```bash
docker compose up --build
```

После запуска:

| Компонент | Адрес |
| --- | --- |
| ShareIt Gateway | `http://localhost:8080` |
| ShareIt Server | `http://localhost:9090` |

Для остановки приложения:

```bash
docker compose down
```
